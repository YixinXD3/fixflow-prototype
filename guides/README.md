# Guides

This directory contains teaching material supplied with the starter repository. Guides explain practices, introduce concepts, and provide exercises. Project teams should record their own evidence, choices, and outcomes in `docs/`.

## Initial guides

- [Getting started](getting-started.md)
- [Working with agents](working-with-agents.md)
- [Developing agent skills](developing-agent-skills.md)

Guides may link to project templates, but reusable agent output templates belong with the relevant skill under `.agents/skills/`.
